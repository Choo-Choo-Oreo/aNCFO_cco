Hearts of Iron 4 can be launched with a number of additional command line arguments (or launch options in Steam). Hearts of Iron 4 command line arguments cannot include spaces or hyphens, except for the hyphen at the start of each argument. Quotes cannot be used to get around this limitation. So if, for example, one wishes to use <code>-start_save=</code> to load a save on startup, the filename cannot include spaces or hyphens.

| <code>-auto_run=TEXT</code>
|Executes the <code>run TEXT</code> [[console command]] when a game is started/loaded, allowing to execute more commands.
|-
| <code>-autosave=INTERVAL</code> || Overrides the autosave interval in the user's settings.txt file. Can be one of the following: <code>NEVER</code>, <code>DAILY</code>, <code>WEEKLY</code>, <code>MONTHLY</code>, <code>HALFYEAR</code>, <code>YEARLY</code>
|-
| <code>-autosave_count=N</code> || Overrides the debug_saves count in the user's settings.txt file. Specifies how many autosave files are kept before the oldest one is deleted when creating a new one.
|-
| <code>-checksum</code> || Computes and writes out the overall checksum and the checksum of each individual game data file to [[Modding|user directory]]'s {{path|logs/system.log}}. Useful when trying to identify if there is a modification to a single file, or some other file that exists but shouldn't, throwing off the checksum and blocking multiplayer.
|-
| <code>-crash_data_log</code>
|Collects data on errors based on crashes that occur with critical bugs and malfunctions. Including if a buggy mod is activated from the launcher.
|-
| <code>-debug</code> || Indicates that the game should be run in debug mode, enabling a variety of extra behavior to help with development or testing. Some of the features can be turned on from the game console using the <code>debug</code> [[console command]].
|-
| <code>-dump_script_doc</code> || Creates the {{path|script_documentation.json}} file (which lists [[Effects]], [[Triggers]], [[Modifiers]], and [[Variables#Game variables|Game variables]]) in the game's folder instead of launching the game.
|-
| <code>-gamelog</code> || 
|-
| <code>-hands_off</code> || Automatically starts a 1936 game as {{flag|Haiti}},<ref>{{cd|NGame|HANDS_OFF_START_TAG}} in [[Defines]].</ref> unpaused, running at maximum speed, with human AI turned on. Additional effects include enabling the AI testing, test logs, and view, disabling the end screen, and disabling frame smoothing.
|-
| <code>-historical</code><br/><code>-historical=no</code><br/><code>-historical=yes</code> || Forces the historical focus gameplay setting on or off. Only works in conjunction with any <code>auto-start</code> option, like {{nowrap|<code>-hands_off</code>}} or {{nowrap|<code>-start_tag</code>.}} The default value in game is <span style="white-space:nowrap"><code>-historical=yes</code>,</span> so only <span style="white-space:nowrap"><code>-historical=no</code></span> has any real effect currently.
|-
| <code>-human_ai</code> || Turns human AI on, so that even the country that the player is controlling is managed by AI.
|-
| <code>-logpostfix=TEXT</code> || Prepends the provided text to the beginning of log file names. Useful when running multiple instances of the game on a single machine, such as for multiplayer testing.
|-
| <code>-logprefix=TEXT</code> || Appends the provided text to the end of log file names. Useful when running multiple instances of the game on a single machine, such as for multiplayer testing.
|-
| <code>-noai</code> || Turns off all AI in the game by default, equivalent to automatically applying the <code>ai</code> [[console command]] with the in-game console.
|-
| <code>-nofilewatcher</code> || Turns off the file watcher, which observes game folders and reloads databases or UI when files change. Off by default in Release, but is turned on by {{nowrap|<code>-debug</code>.}}
|-
| <code>-nolauncher</code>
| Skips the launcher and resumes the last game with the enabled mods listed in the [[Modding|user directory]]'s {{path|dlc_load.json}}, usually the last enabled mods.
|-
| <code>-start_minimized</code> || Starts the application minimized to the taskbar. Only available in Debug and Release_D. Only implemented for Windows at the time of writing.
|-
| <code>-start_save=TEXT</code> || Skips the main menu and directly loads a save file (specified by file name but without the ".hoi4" extension).
|-
| <code>-start_speed=N</code> || Sets the initial speed of the game (0-4).
|-
| <code>-start_tag=TAG</code> || Skips the main menu and directly starts a 1936 game as the [[country]] specified by TAG.
