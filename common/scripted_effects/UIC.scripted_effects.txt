# Unique Ideology Cosmetic (UIC)
#
# aNCFO_uic_subject_effects: fixed lookup of known subject/overlord pairs. Not generic, a subject relationship outside the listed pairs sets nothing.
#
# aNCFO_uic_effects: entry point. Per tag block: IF is_subject, route to aNCFO_uic_subject_effects; ELSE_IF handles the logical points. This is to ensure complete uniquness. Below is some but not all LIMIT's:
#	"has_cosmetic_tag" and "original_tag" should be treated as exclusive.
#	We can have ideologies clump like that of "pluralism" and "semidemocracy" for example.
#	Custom content lock, you can use this to have a unique color tier sytem using "Roman Numeral"
#	NOT = { UIC_has_formable = yes } Limits original tags so that formable UICs function.
#
# UIC Tag types:
#	UIC_[Tag]_ideocos_[Ideology]
#	UIC_[Tag]_ideocos_[Ideology]_[Roman Numeral]
# UIC Cosmetic Tag types:
#	UIC_[Cosmetic Tag Name]_ideocos_[Ideology]
#	UIC_[Cosmetic Tag Name]_ideocos_[Ideology]_[Roman Numeral]
# UIC Subject Tag types:
#	UIC_subject_[Tag 1]_ideocos_[Ideology]_master_[Tag 2]
#
# Colors in cosmetic.txt are not always unique per new tag added, reusing default country color is expected practice. Typically for UIC Tag types, if a country starts as Ideology X then they wont have a color for Ideology X.
# When using the UIC Subject Tag types, its expect for the Subject to have a complementary color of the Master. Look at the Ideology of the master in colors.txt if a UIC type doesnt exist in cosmetic.txt.
#
# The block below marked # Template uses literal tag ZZZ, which never matches a real country. It never fires as written. It exists as a copy paste starting point for adding a new tag to this system, not as functioning logic.
