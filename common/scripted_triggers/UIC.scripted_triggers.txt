	# This should prevent country teired logic from causing issues where the formable UIC isnt used.
	# Comprehensive check: true if ROOT holds ANY "formed a new nation" cosmetic
	# tag anywhere in the mod. Nation-specific UIC blocks (CPF/MJU/SDP/MRC/UEK)
	# guard on NOT = { UIC_has_formable = yes } so their own default ideology
	# colour never overwrites a formable the country has already obtained.
